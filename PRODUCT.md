## Platform
Web · React + TypeScript + Vite.

## Product Purpose
An independent local redesign of the public Best Western Plus Hotel Tejvivaan website in Visakhapatnam, India. The new site is a single-property experience. Booking actions continue to Best Western’s official booking page; this demo does not process bookings or payments.

## Capabilities and Constraints
Public routes cover hotel/about, three room types, dining, meetings and events, services, gallery, offers, contact, five journal articles and privacy/terms summaries. Interactive features include source page aliases, hotel photo filters/lightbox, event layout comparison, menu viewer, saved hotel, direct call/email/maps, and a locally stored enquiry draft. Existing synthetic profile, favorites, points, wallet and historic demo bookings remain local and explicitly labeled. Never imply live inventory, current offer validity, real rewards or external enquiry delivery. Do not copy private account information into source or documents.

The official booking destination for all primary stay actions is https://www.bestwestern.com/en_US/book/visakhapatnam/hotel-rooms/best-western-plus-tejvivaan/propertyCode.76993.html. Best Western owns live dates, rates, availability, reservations and payment.
